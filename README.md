# 补

「补」是一个本地优先的个人生活记录 App，用来训练、喝水、戒烟、处理待办、设置独立提醒和记账。

- 源码与安装包：[github.com/bgwfsj/bu-app](https://github.com/bgwfsj/bu-app)
- 最新安装包：[Releases](https://github.com/bgwfsj/bu-app/releases/latest)
- 所有数据默认只保存在当前设备

## 安装

1. 从最新 Release 下载 `bu-<版本号>.apk`。
2. 首次安装时，允许系统安装未知来源应用。
3. 打开 App 后允许通知权限，并在需要时允许“闹钟与提醒”权限。

小米、Redmi 用户还需要：

- 允许自启动
- 省电策略设为“无限制”
- 在特殊权限中允许“闹钟与提醒”

## 首页

首页提供训练、喝水、戒烟、待办、记账和提醒入口。

- 功能页可以左右滑动，顺序为：训练 → 喝水 → 戒烟 → 待办 → 记账 → 提醒。
- 底部单字入口与滑动顺序一致。
- 当天有待办提示时，首页会显示红色提示卡；右侧 `×` 只关闭当天。
- 右上角 `⋯` 进入设置。

## 训练

1. 在训练计划里选择动作、组数或目标时长。
2. 点击计划旁的“开始”，训练计时随即开始。
3. 每完成一组或一个时长动作后点击完成，系统会记录本次训练累计时间。
4. 完成计划最后一项后自动结束训练。
5. 训练中可增加、删除动作或调整目标。
6. 可以补记过去日期的训练。

日历会标出训练日和放纵餐。两个月以前的月份只保留训练次数和放纵餐次数。

## 喝水

- 点击快捷水量记录饮水。
- 可以输入自定义毫升数。
- 可修改每日目标。
- 页面显示今日记录、近 7 天趋势和历史。

## 戒烟

- 首次进入时设置戒烟起始时间。
- 页面显示已坚持时间、身体恢复阶段和下一阶段进度。
- 顶部 `×` 用于记录破戒并重新开始计时。

## 待办

- 支持仅一次、每天、工作日、周末和自定义日期。
- 今天的待办可以直接勾选完成。
- 点击“改”可以编辑内容或重复方式。
- 删除不会立即彻底删除，而是移入归档。
- 过期的一次性待办和已经结束的自定义待办会自动归档。
- 归档默认折叠，可以“移回”或“彻底删除”。
- 普通待办向左拖动可归档；归档项向右拖动可移回、向左拖动可彻底删除。
- 每天晚上可以使用系统通知汇总未完成待办。

## 提醒

提醒与待办独立保存，支持：

- 仅一次
- 每天
- 每周
- 每月
- 每年

通知会直接显示提醒内容和两个按钮：

- `确认`：收起通知
- `稍后`：进入 App，输入 1–1440 分钟后再次提醒

一次性提醒完成后、手动删除的提醒都会进入归档。归档项可以移回或彻底删除。

普通提醒向左拖动可归档；归档项向右拖动可移回、向左拖动可彻底删除。长按后可进入更明显的拖拽状态。

## 记账

- 使用事件树管理根事件和多级子事件。
- 点击箭头展开或折叠事件，默认全部折叠。
- 父事件汇总整棵子树的金额。
- 支持 CSV 导入和当前事件子树导出。
- 月度总览可查看历史月份、分类占比和逐笔记录。

## 设置

右上角 `⋯` 打开设置页：

- 导出完整备份
- 从完整备份恢复
- 检查 GitHub 更新
- 查看关于和版本更新记录

完整备份包含训练、喝水、戒烟、待办、提醒、归档和记账。建议升级前先导出一份备份。

## 通知排障

如果到时间收不到通知：

1. 确认系统通知权限已开启。
2. 确认“闹钟与提醒”特殊权限已开启。
3. 小米/Redmi 开启自启动并关闭省电限制。
4. 确认提醒时间没有已经过去。
5. 点击设置中的“检查更新”，确保使用最新版本。

## 数据说明

- 数据只保存在 WebView 的 `localStorage`。
- 卸载 App 会清空本地数据，卸载前务必导出备份。
- 没有账号系统、云同步或后台服务器。
- 应用只在主动检查更新时访问 GitHub。
