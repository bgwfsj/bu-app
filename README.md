# 补

「补」是一个本地优先的个人生活记录 App，用来训练、喝水、记录三餐、戒烟、处理待办、设置独立提醒和记账。

- 源码与安装包：[github.com/bgwfsj/bu-app](https://github.com/bgwfsj/bu-app)
- 最新安装包：[Releases](https://github.com/bgwfsj/bu-app/releases/latest)
- 所有数据默认只保存在当前设备

## 安装

1. 从最新 Release 下载 `bu-<版本号>.apk`。
2. 首次安装时，允许系统安装未知来源应用。
3. 打开 App 后允许通知权限，并在需要时允许“闹钟与提醒”权限。

从 5.7 或更早的调试签名版本升级到 5.8 时，需要先导出完整备份，再卸载旧版、安装新版并恢复数据。从 5.8 开始，后续版本会固定使用同一发布签名，可以直接覆盖更新。

小米、Redmi 用户还需要：

- 允许自启动
- 省电策略设为“无限制”
- 在特殊权限中允许“闹钟与提醒”

## 首页

首页提供训练、喝水、三餐、戒烟、待办、记账和提醒入口。
- 首页支持“经典布局”和“拼图布局”两套样式，可在设置页切换。

- 功能页可以左右滑动，顺序为：训练 → 喝水 → 三餐 → 戒烟 → 待办 → 记账 → 提醒。
- 底部单字入口与滑动顺序一致。
- 当天有待办提示时，首页会显示红色提示卡；右侧 `×` 只关闭当天。
- 首页提醒提示只在提醒时间已经到达、且本次还没有确认或稍后时显示；未来提醒不会提前出现。
- 首页底部显示“此间相逢 X 次 · 今日 Y 次”访问统计。
- 访问次数和对应文案显示在首页左上角。
- 统计下方会显示与特殊累计次数或今日次数对应的文案；今日次数的 1–20 各准备了 5 条。
- 首次启动和从其他应用返回会计数；息屏恢复、开机自启动和 App 内返回首页不计数。
- HTML 预览使用浏览器本地计数，方便检查样式；安装版使用 Android 原生生命周期计数。
- 右上角 `⋯` 进入设置。

## 训练

1. 在训练计划里选择动作、组数或目标时长。
2. 计划里的动作可以上下调整顺序，也可以重复添加同一个动作。
3. 点击计划旁的“开始”，训练计时随即开始。
4. 每完成一组或一个时长动作后点击完成，系统会记录本次训练累计时间。
5. 完成计划最后一项后自动结束训练。
6. 训练中可增加、删除动作或调整目标。
7. 可以补记过去日期的训练。

日历用蓝点标出训练日、黄点标出放纵餐，同一天可以同时显示两个圆点；只有今天的日期显示边框。两个月以前的月份只保留训练次数和放纵餐次数。

## 喝水

- 点击快捷水量记录饮水。
- 可以输入自定义毫升数。
- 可修改每日目标。
- 页面显示今日记录、近 7 天趋势和历史。

## 三餐

- 点击整行“吃饭啦！”按钮会记录当前时间，不要求先选餐次。
- 系统按时间自动归入早餐、午餐、下午茶、晚餐或夜宵；21:00 后归为夜宵。
- 正餐理想时间为早餐 06:30–09:00、午餐 11:30–13:00、晚餐 17:30–19:30。
- 每次记录后会结合当前时间和与上一顿的间隔给出评价，并附带一条一般性的健康饮食提示。
- 页面计时显示距离下一顿理想正餐开始时间的倒计时和进度条；如果当前正处在理想就餐时间，则改为显示这段时间还剩多久。
- 只提示理想时间段，并会跳过今天已经记录过的正餐。
- 今日记录默认只展示三餐，整块记录可以折叠，下午茶和夜宵继续单独折叠。
- 右上角 `⋯` 菜单支持按日期和时间补记；底部月历按规律正餐数显示绿、黄、红或叉，夜宵显示小点。
- 三餐记录属于完整备份的一部分。

## 戒烟

- 首次进入时设置戒烟起始时间。
- 页面显示已坚持时间、身体恢复阶段和下一阶段进度。
- 顶部会显示历史最久的一次和那次破戒日期；当前这次达到历史最长时显示“你第一次走这么远”。
- 顶部 `×` 用于记录破戒并重新开始计时。

## 待办

- 支持仅一次、每天、工作日、周末、自定义日期、每周、每月和每年。
- 今天的待办可以直接勾选完成。
- 点击待办条目本身可以编辑内容或重复方式，归档里的待办不能编辑。
- 待办内容较长时会自动换行，不再截断成一行。
- 点击“转”可以把待办转换为独立提醒，原待办保留在归档中。
- 一条待办只生成一条提醒；工作日、周末和自定义多日期待办会简化成最近一次日期。
- 删除不会立即彻底删除，而是移入归档。
- 过期的一次性待办和已经结束的自定义待办会自动归档。
- 归档默认折叠，可以“移回”或“彻底删除”。
- 普通待办向左拖动可归档；归档项向右拖动可移回、向左拖动可彻底删除。
- 每天晚上可以使用系统通知汇总未完成待办。
- 待办页右上角 `⋯` 菜单可以设置或修改每日提醒时间。

## 提醒

提醒与待办独立保存，支持：

- 仅一次
- 每天
- 每周
- 每月
- 每年

提醒页右上角 `⋯` 打开提醒设置，其中可以关闭或开启首页提醒提示。

通知会直接显示提醒内容和两个按钮：

- `稍后`：打开 App 的时间输入框，默认 10 分钟，可改为 1–1440 分钟
- `确认`：一次性提醒会标记为已完成并归档，不再只是收起通知

点击通知正文会进入对应页面并弹出处理框，可以在弹框里选择确认，或输入 1–1440 分钟后再次提醒；App 已在后台时也会正常弹出。

提醒通知恢复为 5.7 的稳定实现：使用系统标准通知和“确认”“稍后”两个操作，保留原通知通道设置。

提醒列表和归档里的长内容会自动换行。

仅一次的独立提醒选择“稍后”后会进入归档并标记为“已稍后”，补发的稍后通知仍会按设定时间触发。

一次性提醒完成后、手动删除的提醒都会进入归档。归档项可以移回或彻底删除。
从归档移回已经过期的仅一次提醒时，会保留原来的日期，不会自动改到后一天。

普通提醒向左滑动可归档；归档项向右滑动可移回、向左滑动可彻底删除。提醒不使用长按拖拽。

在提醒或待办条目上左右滑动只操作该条记录，不会同时切换大页面。点击正常状态的提醒条目可以编辑，归档里的提醒不能编辑。

提醒按仅一次、每天、每周、每月、每年分组，空分组不显示。每个分组会记住展开或折叠状态。点击“转”可以把提醒转换为待办，原提醒保留在归档中；转换时独立提醒的具体钟点不会带入待办。

## 记账

- 使用事件树管理根事件和多级子事件；事件区域和事件树节点默认折叠。
- 点击“事件”展开总览，点击箭头展开或折叠某个事件分支。
- 父事件汇总整棵子树的金额。
- 可以修改当前事件名称，也可以把不再使用的事件树归档。
- 右上角记账设置中可新建根事件或当前事件的子事件。
- 可以按日期、分类、备注或金额搜索当前事件的记录。
- 最近记录位于“记一笔”上方，默认显示最新 3 笔；点击标题可依次展开全部、完全折叠、恢复最近 3 笔。
- 搜索框位于“记一笔”下方；搜索时显示全部匹配记录。
- 点击整条账目记录可以编辑，删除按钮保留在记录右侧。
- 右上角 `⋯` 进入记账设置，可滚动管理事件、分类、CSV 导入导出和归档事件。
- 支持 CSV 导入、导出当前事件子树，以及导出包含归档在内的全部事件。
- 月度总览继续统计已归档事件的历史记录，事件只在主事件树中隐藏。
- 当前事件显示累计花费、本月花费、每月花费历史、分类饼图和分类排行。
- 月度总览可查看历史月份、分类占比和逐笔记录。
- 分类可以新增、编辑和删除；编辑会同步历史记录。

## 设置

右上角 `⋯` 打开设置页：

- 导出完整备份
- 从完整备份恢复
- 清理旧备份，只保留最近 2 份
- 检查 GitHub 更新
- 查看关于和版本更新记录
- 切换首页经典布局或七格拼图布局

完整备份包含训练、喝水、三餐、戒烟、待办、提醒、归档、记账和首页布局设置。建议升级前先导出一份备份。
每次导出或更新前自动创建备份后，会自动清理更早的备份，最多保留最近 2 份。

在应用内检查并确认更新时，App 会先自动导出一份完整备份；只有备份保存成功才会继续下载新版本。

## 通知排障

如果到时间收不到通知：

1. 确认系统通知权限已开启。
2. 确认“闹钟与提醒”特殊权限已开启。
3. 小米/Redmi 开启自启动并关闭省电限制。
4. 确认提醒时间没有已经过去。
5. 点击设置中的“检查更新”，确保使用最新版本。

## 数据说明

- 数据只保存在 WebView 的 `localStorage`。
- 卸载 App 会清空本地数据，卸载前务必导出备份。
- 没有账号系统、云同步或后台服务器。
- 应用只在主动检查更新时访问 GitHub。
